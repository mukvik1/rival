# RIVAL Telegram Bot

Telegram-бот для RIVAL Barbershop.

## Что уже есть

- фирменное меню RIVAL;
- список мастеров и уровней;
- актуальный каталог услуг и цен;
- запись через Telegram: мастер → услуга → дата → желаемое время → контакт;
- заявка сохраняется в SQLite;
- админ получает новую заявку и может подтвердить или отменить её кнопкой;
- клиент видит свои записи в разделе «Мої записи»;
- уведомление клиенту при подтверждении/отмене.

> Важно: текущая версия работает как система заявок. Время считается желаемым до подтверждения администратором. Это сделано специально, чтобы не создавать двойные записи, пока мы не подключили бот к тому же календарю/CRM, который использует rival.team.

## Переменные окружения

- `BOT_TOKEN` — токен Telegram-бота от @BotFather
- `ADMIN_IDS` — Telegram ID администраторов через запятую
- `DB_PATH` — путь к SQLite БД, по умолчанию `rival.db`
- `BOOKING_URL` — ссылка на текущую веб-запись, по умолчанию `https://rival.team/ua/book/master`

## Локальный запуск

```bash
pip install -r requirements.txt
BOT_TOKEN="..." ADMIN_IDS="123456789" python bot.py
```

## Railway

Стартовая команда уже описана в `railway.json`. После подключения репозитория достаточно добавить `BOT_TOKEN` и `ADMIN_IDS`.
